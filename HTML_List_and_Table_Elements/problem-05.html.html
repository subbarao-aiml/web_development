Registration Process

  1. Choose the competition you want to participate in
  2. Open the registration form
  3. Enter your personal and college details
  4. Select the event category
  5. Pay the registration fee if applicable
  6. Submit the registration form
  7. Save your registration reference number

Fest rules

  • Participants must carry ID cards
  • Participants must report when event before start
  • Participants must follow the instructions of the volunteer

Imortant event terms

Open Event
An event open to eligible participants from different groups.
Team Event
An event where multiple participants compete together.
Individual Event
An event where one participant competes individually.
Registration
The process of officially enrolling for an event.
Coordinator
A person responsible for managing an event.
Final Round
The last stage of a competition where finalists compete.
