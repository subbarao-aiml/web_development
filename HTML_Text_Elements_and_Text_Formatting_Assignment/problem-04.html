Mathematics Formula Sheet

Algebra

(a + b)2 = a2 + 2ab + b2

(a - b)2 = a2 - 2ab + b2

a2 - b2 = (a + b)(a - b)

The nth term of an arithmetic progression is an = a + (n - 1)d.

Geometry

For a right-angled triangle, c2 = a2 + b2.

Area of a circle = πr2.

Circumference of a circle = 2πr.

Mensuration

Volume of a cube = a3.

Volume of a cylinder = πr2h.

Surface area of a sphere = 4πr2.
